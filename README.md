# QuickNote — Futuristic Neon Notes App (Backend-Less)

The application is 100% client-side and requires **zero backend servers**.

### ⚡ Quick Start:
```powershell
cd quicknote-app\frontend
npm install
npm run dev
```

App URL: **http://localhost:5173**
